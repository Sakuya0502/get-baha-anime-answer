# 動畫瘋動漫通答案獲取腳本 V0.0.1
讓你可以在[動畫瘋](https://ani.gamer.com.tw/)直接獲取動漫通的答案

## 使用方式
1. 下載Tampermonkey
    * 至[此](https://www.tampermonkey.net/)下載，若已下載則無需再次下載

2. 於greasyfork安裝腳本
    * 點擊[此處](https://greasyfork.org/zh-TW/scripts/597348)安裝腳本

3. 開始使用
    * 完成以上步驟後即可開始使用，獲取答案的按鈕位於網頁頂部，點擊後就會顯示今天動漫通的答案
    ![example_image](image.png)
